# CAPTCHA Generator App (C# Windows Forms)

This is a Windows Forms application developed in C# that demonstrates different types of CAPTCHA systems:

- Text-based CAPTCHA
- Image-based CAPTCHA (simulated)
- Math-based CAPTCHA
- Checkbox-style CAPTCHA ("I'm not a robot")

## How to Run

1. Open `CaptchaGeneratorApp.csproj` in Visual Studio.
2. Build and run the project.
3. Click buttons to test different CAPTCHA types.

## Project Files

- `MainForm.cs` – Main UI and logic.
- `Program.cs` – Entry point for the app.
- `.csproj` – Visual Studio project file.
